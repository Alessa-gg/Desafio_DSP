# TransLogística SV - Sistema de Gestión de Flota

##  Introducción
Este proyecto consiste en una aplicación web desarrollada en **ASP.NET MVC** para la empresa de transporte **TransLogística SV**, diseñada con el objetivo de administrar de manera eficiente los vehículos de su flota. El sistema implementa un CRUD completo (Registro, Lectura, Actualización y Eliminación) aplicando de forma estricta los pilares de la **Programación Orientada a Objetos (POO)**. 

A través del uso de una clase abstracta y herencia, el sistema gestiona diferentes tipos de vehículos (`Camion`, `Automovil`, `Motocicleta`), calculando sus costos de mantenimiento anual mediante **polimorfismo** puro sin recurrir a estructuras condicionales. Para la persistencia de datos, se utiliza una capa de almacenamiento en memoria basada en la estructura `Dictionary<string, Vehiculo>`, garantizando un rendimiento óptimo y una gestión segura utilizando la placa como identificador único.
